# PARSIC

زبان مستقل آزمایشی پارسیک با الهام از خط میخی پارسی باستان.

## امکانات نسخه 2
- مترجم تبدیل حروف فارسی و پارسیک
- تبدیل دوطرفه حروف نگاشت‌شده
- فرهنگ لغت آفلاین
- صفحه‌کلید اختصاصی اندروید
- الفبای نمایشی
- قواعد پایه زبان
- پشتیبانی از نویسه‌های Unicode
- منابع اولیه توسعه یکپارچه‌سازی سیستم

## ساخت APK
به GitHub بروید و از بخش Actions آخرین اجرای موفق را دانلود کنید.

## نکته
تبدیل حروف با ترجمه معنایی یکسان نیست.
PARSIC هنوز یک زبان در حال توسعه است.
APK به‌تنهایی زبان سیستم HyperOS را اضافه نمی‌کند.
