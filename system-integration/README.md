# PARSIC system integration

This folder contains development resources for future Android ROM
localization work.

Included language identifier:
- Development identifier: qps
- Script identifier: Xsux
- Writing direction: LTR

Important:
A normal Android APK cannot add a new complete system locale to
HyperOS language settings or translate system applications.

Full system integration requires ROM/framework resource integration,
system image testing, and device-specific compatibility work.

This project does not produce a flashable ROM.
Do not flash these files as a recovery package.
