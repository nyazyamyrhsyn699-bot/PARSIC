# PARSIC Language Specification

Version: 2.0 Development

PARSIC is an experimental constructed language project inspired by
Old Persian cuneiform.

## Writing system
- Unicode Old Persian block: U+103A0–U+103BF
- Writing direction: left to right
- 32 experimental character mappings

## Basic grammar proposal
- Default word order: Subject Object Verb (SOV)
- Proposed plural suffix: -an
- Proposed possessive suffix: -i
- Adjectives follow nouns

## Important distinction
The current converter performs character transliteration.
It does not yet perform full semantic translation.

The dictionary and grammar are an initial working specification.
The vocabulary and grammar require linguistic development and review.
